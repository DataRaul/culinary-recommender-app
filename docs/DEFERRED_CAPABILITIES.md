# Deferred Capabilities

| Capability | State | Activation boundary |
|---|---|---|
| D1 Nutrient Gap Awareness | DEFERRED | authoritative healthy-population evidence layer; no deficiency diagnosis |
| D2 Existing Supplement Routine Checker | DEFERRED | dedicated evidence/safety layer; no prescribing or individualized therapeutic dose |
| D3 Recipe Images | DEFERRED | only after text/data/recommendations are strong |
| D4 Local Grocery Price Intelligence | DEFERRED | lawful reliable price source or user/receipt evidence |
| D5 Fitness Integration | DEFERRED | thin generalized Knowledge Core routing boundary; fitness and culinary product/runtime ownership remain separate |
| D6 Advanced Culinary Exploration | DEFERRED / BRAIN INPUTS ACTIVE | private Brain/Atlas technique, regional and transformation reasoning may mature independently; public curriculum/exploration behavior remains separately gated |
| Culinary & Nutrition Brain P0 / Atlas | PRIVATE DEVELOPMENT ACTIVE / PUBLIC BEHAVIOR GATED | reusable reasoning lives in Knowledge Core; only narrow reviewed pinned public-safe exports may enter this app through the generalized KC platform boundary |

Brain/Atlas development is no longer accurately described as only `FOUNDATION BUILT`: the private Knowledge Core branch contains active World Recipe Atlas, transformation, technique-prerequisite and corpus-critic work. That private maturity does not imply public runtime activation.

The app consumes Knowledge Core through the same generalized platform-adapter architecture used by other downstream repositories. See `docs/KNOWLEDGE_CORE_INTEGRATION.md` and `docs/BRAIN_ADAPTER_CONTRACT.md`.

Brain authorization does not permit runtime access to private Knowledge Core, automatic recipe admission, automatic ranking changes or automatic Lab → Brain promotion.

V0/V1 product failures, nutrition blockers and corpus-review gaps should continue to become evidence for Brain source-gap/research prioritization rather than being hidden by runtime LLM calls. Canonical Brain promotion remains separately governed in Knowledge Core.
