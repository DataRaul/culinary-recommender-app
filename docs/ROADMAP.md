The V0 corpus is deliberately small and quality-oriented. Corpus expansion is evidence-driven rather than a recipe-count race.

Deployment deliberately uses the simplest public static pattern: GitHub Pages from `main` / repository root. Validation remains separate in the public `validate.yml` workflow.
