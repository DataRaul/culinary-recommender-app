# Contributing

This project is in gated V0 development. Contributions should preserve deterministic behaviour, provenance and the hard-constraint boundary.

For recipe/data contributions:
- do not copy expressive third-party recipe text or photographs;
- record source/licence/provenance explicitly;
- keep ingredient quantities and instructions complete;
- use canonical ingredient IDs or extend the ontology deliberately;
- mark nutrition and cost confidence honestly;
- add deterministic tests for new hard constraints or normalization rules.

Before committing, run `npm run validate`.
